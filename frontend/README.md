# WatchDog frontend

The WatchDog mobile application uses Expo SDK 57, React Native, and Expo Router.

## Development

Install dependencies and start Metro from this directory:

```bash
npm install
npx expo start
```

Metro will provide options for Expo Go, Android, iOS, and web. Application routes live in `src/app`, while shared UI and feature code live under `src`.

Refer to the [Expo SDK 57 documentation](https://docs.expo.dev/versions/v57.0.0/) when changing Expo configuration or native behavior.
